# 规则库说明（RULES）

本文档说明规则引擎的决策逻辑、覆盖范围与维护方法，供审阅与贡献参考。
规则实现位于 `src/rules/`：`questions.ts`（题库与推导函数）、`evaluate.ts`（结论生成）。

## 决策漏斗（新项目申报评估）

```
第 1 层 身份识别
  中方单位 / 外方单位 / 港澳内资实控（视为中方）/ 不确定 → 股权 50% + 实控两题判定
  · 外方单位：采集、保藏、以提供方身份出境 → 直接判定禁止（条例第 7 条）
  · 判定不清 → 标记灰色地带，转人工咨询

第 2 层 资源识别
  材料：全血 / 组织 / 细胞 / 精液 / 脑脊液 / 胸腹腔积液 / 血骨髓涂片 / 毛发（带毛囊）→ 受监管
        尿液 / 粪便 / 血清 / 血浆 / 无细胞分泌物 → 豁免（FAQ 口径，B 级）
  信息：基因 / 基因组 / 转录组 / 表观组 / 核酸类生物标志物 → 受监管
        临床 / 影像 / 蛋白质 / 代谢数据 → 不纳入（细则第 2 条）
  · 仅豁免材料 + 无受监管信息 → 整体不纳入（附"检测产生信息仍可能纳入"提示）

第 3 层 活动识别（多选）
  采集 / 保藏 / 境内利用 / 国际合作 / 材料出境 / 信息对外提供

第 4 层 触发与豁免（按活动逐条评估，详见下表）
```

## 申报轨道判定表

| 活动 | 触发条件 | 结论 | 主要依据 |
|---|---|---|---|
| 采集 | 重要遗传家系 / 特定地区 / 大规模人群研究 >3000 例 | 采集许可 | 条例第 11 条、细则第 27 条 |
| 采集 | >3000 例但属上市许可目的临床试验 | 豁免 | 细则第 27 条 |
| 采集 | 同时符合保藏或国际合作范围 | 被吸收，不单独申报 | 细则第 29 条、FAQ 一.3 |
| 保藏 | 长期保存建库 | 保藏许可（+年报 1.31） | 条例第 14 条、细则第 28/30 条 |
| 保藏 | 教学目的 / 方案约定临时存储 | 不构成保藏 | 细则第 28 条 |
| 境内利用 | 纯中方 | 无审批（伦理 + 知情同意） | 条例第 18 条 |
| 国际合作 | 外方实质参与 + 非上市目的（含 IIT） | 国际合作科研许可 | 条例第 21/22 条 |
| 国际合作 | 上市目的临床试验 + 境内检测分析 + 不出境 | 临床试验备案 | 条例第 22 条、细则第 32 条 |

## 变更评估（已获批项目管理）

| 事项类型 | 变更审批 | 书面说明（无需审批） |
|---|---|---|
| 采集许可 | 参与单位 / 目的 / 方案内容 / 名称（FAQ 一.4） | — |
| 保藏许可 | 目的 / 方案 / 内容 / 名称 | — |
| 国际合作许可 | 目的内容、人遗种类数量用途、申办方/组长/CRO/第三方实验室（细则 46） | ≤10% 数量、其他参与单位、法人名称、不涉及人遗的方案变更（细则 47） |
| 临床试验备案 | 人遗种类数量用途、合作方/方案/内容/目的（细则 53） | 不涉及人遗变化的方案变更（细则 53） |

特殊情形：备案转许可（暂停 → 申请许可，FAQ 二.6）；许可转备案（变更时按整体内容办备案，FAQ 二.7）；合作方变外方（暂停 → 申报国际合作，FAQ 二.4）。

## 置信度分级约定

- **A · 法规条文**：条例 / 实施细则明文
- **B · 官方解答口径**：《人类遗传资源管理常见问题解答》（2023.09）
- **C · 实践惯例**：无明文规定的通行做法

结论生成时按以上来源打标；B/C 级结论在报告页与 Word 导出中均带提示语。

## 主管部门口径

全库统一以**国家卫生健康委员会**为受理机关表述。引用实施细则与 FAQ 原文涉及"科技部"的，在引用附注中说明 2023 年机构改革职责划转，不改动原文表述。

## 如何维护规则

1. 法规修订 / 新 FAQ 发布 → 修改 `evaluate.ts` 中对应结论、引用与阈值
2. 新增触发情形 / 豁免 → 在 `questions.ts` 加题（含 `when` 条件），在 `evaluate.ts` 加分支
3. 在 `smoke-test.mts` 添加对应用例，运行 `npm run test:rules` 全量回归
