# 规则库说明（RULES）

本文档说明规则引擎的决策逻辑、覆盖范围与维护方法，供审阅与贡献参考。
规则实现位于 `src/rules/`：`questions.ts`（题库与推导函数）、`evaluate.ts`（结论生成）。

> **规则库版本 v2.0.0（2026-11-11）**：已按《人类遗传资源管理条例实施细则》（国家卫生健康委员会令第 16 号）完成全量换版，取代原科技部令第 21 号（2023）。新规 8 章 61 条，条号全量重排、无过渡期。逐条映射见 `docs/换版条号映射-16号令.md`。

## 决策漏斗（新项目申报评估）

```

  中方单位 / 外方单位 / 港澳内资实控（可参照中方）/ 不确定 → 股权 50% + 实控两题判定
  · 外方单位：采集、保藏、以提供方身份出境 → 直接判定禁止（条例第 7 条、细则第 9 条）

  材料：所有类型细胞 / 全血 / 组织或组织切片 / 器官 / 骨髓 / 唾液（含脱落细胞）/ 羊水绒毛脐血等产前样本 /
```

## 申报轨道判定表

| 活动 | 触发条件 | 结论 | 主要依据 |
|---|---|---|---|
| 采集 | 清单目录内重要遗传家系 / 特定地区 / 大规模人群研究 >10000 例 | 采集许可 | 条例第 11 条、细则第 16 条 |
| 采集 | >10000 例但属上市许可目的临床试验 | 豁免 | 细则第 16 条 |
| 采集 | 禁拆分、化整为零规避；学术论文比对发现违规 | 反规避提示 | 细则第 16 条第 2 款 |
| 采集 | 同时涉及保藏 / 国际合作科学研究 | 被吸收，不单独申报 | 细则第 20 条 |
| 保藏 | 仅用于科学研究的长期建库 | 保藏许可（+年报 1.31、技术规范） | 条例第 14 条、细则第 21/22/24 条 |
| 保藏 | 临床诊疗/教学为主兼顾科研、已上市药械生产目的、临时存储 | 不构成保藏 | 细则第 21 条 |
| 境内利用 | 纯中方 | 无审批（伦理 + 事先知情同意） | 条例第 18 条、细则第 6/7 条 |
| 国际合作 | 外方实质参与 + 非上市目的（含 IIT） | 国际合作科研许可 | 条例第 21/22 条、细则第 26 条 |
| 国际合作 | 上市目的临床试验 + 境内检测分析 + 不出境 | 临床试验备案（同日确认） | 条例第 22 条、细则第 27/28 条 |

| 国际合作 | 外方仅资助 / 仅 EDC 等服务方为外方 | 豁免 | FAQ 二.5 / 二.2（B 级） |

| 信息对外提供 | 已公开 / 协议约定且已列明接收方 / 境外上市注册 | 免单独事先报告 | 细则第 41 条 |

## 置信度分级约定

- **A · 法规条文**：条例 / 实施细则（含 2026 版新规）明文
- **B · 官方解答口径**：《人类遗传资源管理常见问题解答》（2023.09）、2025.03 版、之一至之五
- **C · 实践惯例**：无明文规定的通行做法

结论生成时按以上来源打标；B/C 级结论在报告页与 Word 导出中均带提示语。
注：2023.09 FAQ 依据已废止的旧版细则，涉及安全审查、外方伦理例外的口径以后续服务指南为准，报告中已加"以新细则为准"附注。

## 主管部门口径

全库统一以**国家卫生健康委员会**为受理机关表述，省级为**省级人民政府人类遗传资源主管部门**。2026 版细则发布的机关即为国家卫健委，引用原文无需再作"职责划转"附注；仅在引用旧 FAQ 原文时说明其依据旧规制定。

## 如何维护规则

1. 法规修订 / 新 FAQ 发布 → 修改 `regulations.ts`（版本元数据）、`evaluate.ts`（结论/引用/阈值）与 `glossary.ts`（术语）
2. 新增触发情形 / 豁免 → 在 `questions.ts` 加题（含 `when` 条件），在 `evaluate.ts` 加分支
3. 在 `smoke-test.mts` 添加对应用例，运行 `npm run test:rules` 全量回归
4. 换版时先写 `docs/换版条号映射-16号令.md` 一类的映射表，再按表逐条替换，避免漏改条号
